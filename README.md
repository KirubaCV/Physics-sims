# Physics Simulations & Numerical Methods

Welcome! This repository contains simple, physics-first Python simulations. These are created as companion pieces to my weekly Physics Olympiad problem-solving posts on Substack.

The goal here is to bridge the gap between **analytical physics** (the math we do by hand) and **computational physics** (what happens when we let a computer step through the equations).

## 🚀 The Philosophy
* **Physics First:** The code is kept simple and readable. We care more about the physics (energy conservation, drag, coupled oscillators) than writing highly optimized software.
* **Analytic vs. Numerical:** Every simulation corresponds to a problem solved analytically in the Substack post. We use the simulation to visualize the solution and see where approximations break down.
* **Keep it Short:** Most scripts are under 100 lines. No complex object-oriented programming—just NumPy, Matplotlib, and straightforward loops.

## 📂 Repository Structure
* `simulations/`: Contains the Python scripts (`*.py`).
* `plots/`: Contains the generated graphs (`*.png`) used in Substack posts.
